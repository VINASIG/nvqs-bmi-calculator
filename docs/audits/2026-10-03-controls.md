# Form controls and placeholder distinction

Date: **3 October 2026**. Scope: Vietnamese `/` and English `/en/` in `VINASIG/nvqs-bmi-calculator`. This audit records the rebuilt local site before publication. Exact-commit CI, deployment and public checks are verified separately after push.

## Findings and changes

The owner supplied three screenshots: an open native table selector, an open native date picker and bare numeric placeholders resembling entered measurements. Their original viewport, browser and operating-system details were not established from the clipped images. The before images are preserved without assigning invented viewport labels.

- Replace the native table-selector popup with styled native radio choices. The full labels are touch targets, selected/focused states use existing semantic tokens, and the group retains native keyboard behavior and accessible names.
- Replace the native date popup with a locally rendered calendar in a native HTML modal dialog. It uses local Space Grotesk, existing theme tokens and Lucide controls. Manual ISO date entry remains available and real dates are validated before printing/exporting a record.
- Distinguish examples from values with localized `VD:` / `e.g.` prefixes, the existing small-text size and a softer neutral placeholder role. Entered values retain their normal size/color. All measurement fields remain empty initially and after Clear.

During iteration, keyboard focus escaped the draft calendar, WebKit mouse invocation did not consistently restore focus, enlarged calendar text crowded at 320 px, and radio-label words fragmented immediately above the 760 px breakpoint. Focus containment/restoration, local calendar spacing and intrinsic radio-grid sizing corrected these findings. Browser assertions cover the observed failure conditions.

No BMI arithmetic, physique scoring, legal/medical rule, dependency, identity anchor, supplied artwork, font bytes or existing page breakpoint was changed. Chest remains a separate optional physique indicator and does not enter the BMI calculation.
