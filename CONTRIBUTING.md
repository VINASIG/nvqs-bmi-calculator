# Contribute

Read AGENTS.md and the product, research and toolchain records. Keep changes scoped and preserve existing work. Answer people in their language while keeping technical source and documentation in English.

Medical or legal changes need current primary references, a visible review date and exact boundary regressions. Do not claim professional review, overall recruitment eligibility, diagnosis or new data collection. Keep both product languages complete.

Run check, unit, build and the affected browser/performance checks. Open relevant screenshots. Never weaken an assertion, exclude a browser in CI or raise a budget to excuse a defect. Report the evidence and checks that were not run. Publishing, account changes and messages follow explicit task authorization.

## Contribution licensing

Read [LICENSES.md](LICENSES.md) before submitting material. New contributions use the applicable software, documentation or data scope unless a different compatible license is explicitly identified and accepted. Preserve authorship and third-party notices. Submit only material you have authority to license. This does not require a blanket copyright assignment or grant permission to redesign the official identity assets.
